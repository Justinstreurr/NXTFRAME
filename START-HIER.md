# NXT Frame site op een andere computer

1. Pak de zip uit en open deze map in Claude Code of een terminal.
2. Installeer de packages:      npm install
3. Start de dev-server:        npm run dev
4. Open http://localhost:3000

Lees OVERDRACHT.md: daar staan de stand van zaken, de afspraken en de openstaande vragen.
